# Ronce — toko gelang manik (dummy UTS E-Commerce Lab)

Website statis (HTML, CSS, JavaScript) untuk GitHub Pages.

- `index.html` — beranda, katalog, cara ukur, ulasan
- `tentang.html`, `kontak.html`, `kebijakan.html`
- `js/app.js` — data produk, keranjang, checkout ke WhatsApp (ganti nomor WA di baris paling atas)
- `img/` — foto produk (ganti dengan foto asli, nama file sama)
